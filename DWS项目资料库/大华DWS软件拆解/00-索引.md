> 本知识库用于记录对**大华科技 LogisticsPlatform（DWS）**的拆解分析，以及用 **Node.js 重建该项目的方案**。
> 当前版本目标：**V1 对标 DWS 六面扫方案，只做读码（扫码）功能，不包含称重与体积测量**。
> 相机全部采用**智能相机（相机端自带解码）**，本地软件不做任何图像解码，只负责收集六面相机识别出的条码、归并去重并输出。

## 关键结论速览

- 原系统是 **C#/.NET Framework WinForms 桌面程序**，围绕"相机采图 → 算法读码 → 规则过滤 → 多源数据绑定 → 结果输出 → 历史统计"的管道式架构。
- 原生核心是 **LogisticsBase64.dll（C++ SDK）**，上层 C# 通过 P/Invoke 封装（`LogisticsBaseCSharp.dll`）调用，平台层通过事件回调消费结果。
- 原系统内置三种"方案"（Solution）：**DWS**（体积+称重+读码）、**快手 FastScan**（手动放包）、**狂扫 RapidScan**（只读码）。
- 用户 V1 需求（**六面扫 + 只读码 + 智能相机**）在能力上对齐原系统的"DWS 方案"中**只启用读码模块**的运行形态。
- Node.js 重建的最核心技术点变为：**六台智能相机的接入与结果归并（去重、时间窗打包）**，本地不做解码，因此不需要任何图像算法库。
