# 核心模块技术细节

## 1. 图像采集模块（ImageAcqCfg）

### 1.1 图像源模式（`<ImageAcq mode>`）

| mode | 含义 |
|---|---|
| 1 | 自动发现并连接工业相机（可混用） |
| 2 | 按 IP / Key / Id 指定连接（GigE 用 IP，USB3 用 Key/Id） |
| 3 | 线扫相机（工业线阵） |
| 4 | 全部工业相机 |
| 5 | 混合（线扫 + 工业 + 智能） |

### 1.2 触发模式（`<ReadCodeMode triggerMode>`）

| 值 | 模式 | 说明 |
|---|---|---|
| 0 | 自由运行 | 相机连续出图，软件按时间窗汇总 |
| 1 | 硬触发 | 光电传感器触发，最推荐、同步性最好 |
| 2 | 软触发 | 软件发指令触发 |

`mode`（读码子模式）：0 = 手持/普通模式，1 = 线扫模式（配合 triggerMode=0 即"软触发线扫"）。

### 1.3 过包汇总关键参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `handleResultDelayTime` | 1500ms | 首帧成功后等待其他相机结果的窗口 |
| `firstFrameTimeDiff` | 300ms | 首帧时间差容限 |
| `packageTimeDiff` | 300ms | 相邻包裹判定间隔 |
| `bufferCnt` | 6 | 缓存图像帧数 |
| `reConnectCnt` | 10000 | 断线重连次数（每次间隔约 2s） |
| `randWorkMode` | 1 | 1=任一相机先到即启动汇总 |
| `cacheSize` | 3 | 重复条码过滤窗口 |
| `maxFrameProcessCache` | 40 | 未处理最大图像帧缓存 |

### 1.4 智能相机（SmartCamera）
- NTP 时间同步（自动/手动）；SCPD 组包（多相机结果合并）；
- IO 信号防抖；双帧模式（PhaseMode，一帧 2x2 图像）；
- 输出图像格式：原始 / JPEG / 1/4 裁切。

> [!note] V1 六面扫
> 智能相机（S/R 系列）在相机端完成解码后直接上报条码。**V1 部署 6 台智能相机覆盖顶/底/左/右/前/后六个面**，本地软件不做解码，只收集各相机上报的条码并做时间窗归并、跨相机去重（详见 [[04-六面扫智能相机对接方案]]）。

## 2. 读码算法模块（ExpertCfg）

### 2.1 一维码（BarCode）
- 支持类型（`codeType` 位组合）：A=EAN13、B=Code128、C=Code39、D=EAN8、E=UPCA、F=UPCE、G=Code93、H=ITF25、I=CODABAR、J=PDF417；
- 关键参数：模块宽/窄（elemMin/MaxWidth）、条码尺寸范围、平衡度（准确率 vs 速度，1~10）、单包最大条码数、最大条码宽度；
- 校验：ITF25、Code39 可选校验位；
- 扫描线调试图（enableScanline）。

### 2.2 二维码（DMCode）
- QR / DM / QR&DM（codeType 1/2/3）；极性、镜像、对比度阈值；
- 版本范围、码尺寸、模块尺寸、QR 定位符数；
- 解码能力等级（0 标准 / 1 增强 / 2 更强）、超时。

### 2.3 抠图（ClarityMatting）
- `enableClarity`：清晰度评估（模糊拒收）；
- `enableMatting`：面单/条码区域抠图（输出运单图）。

## 3. 条码过滤规则引擎

两层规则：

1. **SDK 底层规则**（`LogisticsBase.cfg <CodeFilterCfg><Rules>`）：按位组合的快速过滤（见 [[02-包裹过包核心流程]] 第 2.2 节）；
2. **平台规则**（`<PlatformRules>` + `coderules.json`）：支持名称、类型（1D/2D）、优先级、字符类型/长度/起始/结束/包含/正则。启用平台规则后底层规则失效。

快递单号正则库示例（`coderules.json`）：电子面单（8/88/431/6/99/C/CQ/Z/ZB/H/HQ/D/DD/DWB/DZB/DB/G/WB/R02T/B9 等前缀）、YT 开头、R02 开头、12 位普通面单、B0+10 位数字、L+11 位数字、M+14 位数字、JY+10 位数字、BZB+9 位数字。

## 4. 称重模块（WeightCfg，V1 不做）
- 连接：串口（COM1-COM8）/ TCP；
- 协议：静态称 / 通用动态称（7）/ 梅特勒 / 自定义；
- 动态称稳定判定：采样数（SampleNum=5）、精度（20g）、稳定超时（1200ms）、提前超时（ForeTimeout）；
- 自定义协议：`dataLen/startPos/validDataLen` 从报文中截取重量，`startBit/stopBit` 帧头帧尾，`units` 单位换算（g=1, kg=1000）；
- QuickHand：先称后码模式，支持多码求和。

## 5. 3D 体积模块（V1 不做）

### 5.1 动态 3D（Volume）
- 3D 相机（aobi/ty/multiAobi/multiTy/huaray 等模式，见 `calVolumeParam.ini`）；
- 深度图 → 背景建模 → 参考面拟合（`RefPlaneRT.xml`、`cameraToPlatformRT.yml`）→ 包裹分割 → 长宽高/体积计算；
- 关键算法参数：高度范围、最小尺寸、深度采样、参考面更新速度、体积修正系数、托盘补偿、多包裹粘连分割。

### 5.2 静态 3D（StaticVolume）
- 固定放置测量；区域阈值、深度阈值、最小/最大高度、堵塞检测。

## 6. 信息融合与绑定

- 三个数据流（码/重/体积）各有时间戳，通过 `minValidTime~maxValidTime` 窗口对齐；
- 绑定失败 → `OnErrorInfoCallBack` 异常上报（超时/不匹配/3D 超时）；
- 小车号（PLC）与 RFID 作为附加数据源参与绑定；
- `DataChecking` 数据校验：超重/超轻/超长/超短 阈值配置。

## 7. 输出模块

| 通道 | 关键配置 |
|---|---|
| 数据格式 | 模板字符串 + 宏替换 + 十六进制 + 单位（kg/mm³）+ 小数位 + 多码分隔符 |
| TCP 客户端 | 目标 IP/端口、发送间隔、启动延迟 |
| TCP 服务端 | 监听 IP/端口、可指定客户端 IP 白名单 |
| 串口 | 端口/波特率/数据位/校验/停止位 |
| HTTP | URL POST |
| 句柄 | 写入指定文件路径（`vslbWndSendMsg`） |
| 焦点 | 焦点窗口输出 |
| 音频 | OK/NG 语音（按包裹状态或上传状态触发） |
| LED | IP/端口/查询间隔/实时效率/重量显示 |
| 图片上传 | FTP/SFTP/HTTP + 远程目录模板 + 重试 |

## 8. 图像存储模块

- 线程池落盘（`SaveThreadCnt=2`）；命名模板支持 20+ 宏（场地/线体/条码/时间/包裹ID/相机名/结果/物料码）；
- 存储策略：`SingleCameraPolicy`（单相机图）、`AllCameraStoragePolicy`（所有相机图）；
- 文件夹按 `{yyyy}/{MM}/{dd}/{hh}` 分桶；定期删除（`SaveDays`）；
- 水印（时间/条码/重量/体积）。

## 9. 皮带与 PLC

- 皮带类型（`RollingBeltType`）：无 / 串口称（5/6 字节）/ SF 继电器 / 科捷继电器 / TCP 称 / 锐特百世称；
- 控制项：心跳、连续停止、开始后启动称、过包后启动称、无码停止、多码停止、补码模式/直通模式、超时；
- PLC：PackageIDBinder（小车号绑定，20+ 设备商协议）、TCP 客户端/服务端、串口；
- 分拣信号：直通/左/右/前/异常格口（见 `RouteSettingInAndOut.xml`、百世 `SortingConfig`）。

## 10. 日志体系

| 日志 | 位置 | 内容 |
|---|---|---|
| 平台日志 | `CSLog/LogisticsPlatform.log`（log4net 滚动 20MB×50） | 启动/停止/组件/错误 |
| 数据库日志 | SQLite `Log` 表 | 界面可查的操作日志 |
| SDK 日志 | `Log/*.log`（Camera/Comm/Alarm/Default/3DVolume） | SDK 运行日志 |
| 相机日志 | `CamLog/` | 相机 telnet 日志 |
| 更新日志 | `CSLog/updatelog.txt` | Updater 日志 |
