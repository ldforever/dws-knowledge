# 配置体系参考

> 配置文件是理解这套系统最快的入口。原系统所有能力都可以在配置里找到开关与参数。

## 1. 配置文件总览

| 文件 | 层级 | 格式 | 说明 |
|---|---|---|---|
| `Cfg/AppSetting.xml` | 平台层 | XML | 方案、平台插件、存图、显示、输出、皮带、PLC、设备信息、客户插件参数 |
| `Cfg/LogisticsBase.cfg` | SDK 层 | XML(GB2312) | 图像采集、读码模式、过滤规则、称重、输出、算法 |
| `Cfg/coderules.json` | 业务层 | JSON | 快递单号过滤规则（正则） |
| `Cfg/RoutingList.json` | 业务层 | JSON | 路由号 ↔ 路由名 |
| `Cfg/RouteSettingInAndOut.xml` | 业务层 | XML | 进出港 16 格口路由配置 |
| `Cfg/MSCfg.ini` | 平台层 | INI | HOD 云端管理（启停/监控） |
| `Cfg/SettingDoc.xml` | 相机/设备 | XML | 扫码系统参数、相机 MAC、重量串口、存图路径 |
| `BarcodeConfig.ini` | SDK | INI | 扫描线数 |
| `3DCfg/*` | 3D | YAML/XML/INI | 相机外参、参考面、体积参数 |
| `log.config` | 平台 | XML | log4net 日志策略 |
| `appdata.json` | 平台 | JSON | 加载的模块 DLL 与相机型号正则 |
| `OriCfg/` | 出厂 | - | 出厂默认配置（`Cfg` 的还原基线） |
| `Cfg_XBY_backup/` | 备份 | - | 新北洋设备定制备份 |

## 2. AppSetting.xml 关键节点

| 节点 | 关键内容 |
|---|---|
| `<Solution type>` | 方案类型（0=DWS 等） |
| `<Platform><PlatformID>` | 激活的平台插件 |
| `<General>` | 语言、自启动、启动后动作、管理员密码、看门狗、日志级别 |
| `<ImageStorage>` | 存储目录、命名模板、策略、保存天数、水印、质量、保存线程数 |
| `<ImageDisplay>` | 分屏布局（实时图/原图/面单/全景） |
| `<UIConfig>` | 显示统计项、采样数、漏称率/读码率报警阈值、双屏 |
| `<TaskScheduler><AutoExcelExport>` | 定时 Excel 导出 |
| `<Solution><DataChecking>` | 重量/长宽高校验阈值 |
| `<Solution><OutputConfig>` | 数据格式模板、上传重试、TCP 客户端/服务端、串口、HTTP、句柄、焦点、网页、音频、FTP、SFTP |
| `<RollingBelt>` | 皮带类型、串口/TCP、心跳、停止策略、补码 |
| `<PLCCfg>` | 小车号 PLC、RFID PLC、绑定时间窗、TCP/串口 |
| `<DeviceInfo>` | 场地代码、进出港模式、线体号、设备名、SN（加密） |
| `<CodeNumFilter>` | 最大条码数 |
| `<LEDConfig>` | LED 屏 |
| `<CustomConfig>` | 各客户插件参数（顺丰/京东/百世/圆通/邮政/极兔/新北洋等） |

## 3. LogisticsBase.cfg 关键节点

### 3.1 ImageAcqCfg（图像采集）
见 [[02-核心模块技术细节]] 第 1 节。核心参数速查：

```xml
<ImageAcq mode="1" num="6" randWorkMode="1" interPacketTimeout="50"
          cameraTimeout="260" handleResultDelayTime="1500"
          firstFrameTimeDiff="300" packageTimeDiff="300"
          bufferCnt="6" reConnectCnt="10000" MaxPayloadSize="5000" />
<ReadCodeMode triggerMode="1" mode="0" cacheSize="3"
              maxFrameProcessCache="40" lineDebounceAbsTime="30000"
              constantNoread="0" positionFiltering="0"
              doubleFrameMode="0" enableFrameRate="0" frameRate="6" />
<SmartCamera timeSyncMode="1" timeSyncNum="10" scpdEnable="1" scpdDelay="8000"
             inputIODebounceEnable="1" inputIODebounceFilter="10000"
             MultiFrameGroup="0" customMode="0" outImgType="0" jpegQuality="70" />
```

相机声明方式（与 mode=2 配合）：

```xml
<Camera ip="10.33.10.111" enable="1" />          <!-- GigE 用 IP -->
<Camera key="2F0444FPAK00012" enable="1" />      <!-- USB3 用 Key/序列号 -->
<Camera id="Dahua Technology:2F0444FPAK00012" enable="1" /> <!-- 全 ID -->
```

### 3.2 CodeFilterCfg（条码过滤）

```xml
<Rules>
  <Rule val="1"> <!-- 位组合 -->
    <MinCodeSizeParam val="13" />
    <MaxCodeSizeParam val="21" />
    <CodeBeginWithParam><val>bw11111</val></CodeBeginWithParam>
    <CodeRegexParam><val>(?=.*)(.*)</val></CodeRegexParam>
  </Rule>
</Rules>
<PlatformRules>
  <Rule Enable="1" Name="Rule 1" Type="3" Priority="0" RegexStr="(?=.*)(.*)">
    <CharType Enable="0" Type="0" />
    <CodeLength Enable="0" MinLength="0" MaxLength="0" />
    ...
  </Rule>
</PlatformRules>
```

## 5. 输出数据格式示例

```xml
<DataFormat format="{Code},{Weight},{Length},{Width},{Height},{Volume},{Timestamp}"
            weightunit="kg" weightRemainLength="3" volumeunit="mm3"
            volumeRemainLength="0" barcodeSegmentation="_" isHex="False" />
```

V1 读码版建议格式：`{Code},{Timestamp}` 或 `{SiteCode},{Pipeline},{Code},{Timestamp}`。

## 6. 配置加密

- `vendor/model/sn` 等字段在配置中为 **DES 加密值**（`LogisticsPlatformTools.DES`），防止随意篡改；
- `ConfigEncrypter.exe` 用于生成加密配置；
- 平台插件参数（如百世 secret）为明文，字段由插件自行读取。
